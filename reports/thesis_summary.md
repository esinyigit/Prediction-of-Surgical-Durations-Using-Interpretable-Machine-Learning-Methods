# Thesis Summary

## Title

Prediction of Surgical Durations Using Machine Learning Methods

## Short Summary

This thesis focuses on predicting surgical procedure durations using machine learning methods and structured healthcare data.

The main goal is to support operating room planning by estimating how long a surgical procedure may take before it is performed.

## Research Problem

Surgical durations are difficult to predict because they can vary depending on:

- surgery type
- medical unit
- patient-related factors
- surgeon-related factors
- anaesthesiologist-related factors

Machine learning methods can help model these patterns and provide useful duration estimates.

## Main Methods

- data cleaning and preprocessing
- feature engineering
- stratified modeling by short, medium, and long surgeries
- regression modeling
- model evaluation with error metrics
- feature importance and error analysis

## Stratified Duration Groups

The thesis divides surgical procedures into short, medium, and long duration groups. This makes it possible to evaluate whether the model performs differently for simpler, moderate, and longer procedures.

## Practical Value

Better surgical duration estimates can help hospitals improve:

- operating room scheduling
- staff planning
- patient flow
- resource allocation
